# ERROR DNA

AI-powered coding practice platform that identifies recurring programming mistakes and builds a personal Error DNA.

## Current Status

🚧 Hackathon project — actively under development.

### Current Features

- Coding problem library
- Difficulty filtering and search
- Dynamic problem workspace
- Monaco C++ editor
- C++17 code execution
- Multiple test-case execution
- Accepted / Wrong Answer detection
- Compilation error detection
- Runtime error detection
- Time-limit handling
- Test-case results in the UI

### Vision

ERROR DNA goes beyond judging whether code is correct.

It aims to identify **why a developer repeatedly makes mistakes**, detect recurring patterns, and build a personalized coding-error fingerprint.

```text
Code Submission
      ↓
Code Execution
